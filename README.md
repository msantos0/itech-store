# iTech Store — catálogo de iPhones

Landing page responsiva feita com HTML, CSS e JavaScript puro. Inclui catálogo, busca, filtros e links de pedido pelo WhatsApp.

## Como visualizar
1. Extraia o ZIP.
2. Abra `index.html` no navegador. Não precisa instalar dependências.

## Antes de publicar
1. Abra `script.js`.
2. Troque `WHATSAPP_NUMBER` pelo seu telefone com código do país e DDD, somente números. Exemplo de formato: `5511999999999`.
3. Atualize a lista `products`: nome, armazenamento, cor, preço, categoria e imagem.
4. Troque o nome “iTech Store” pela sua marca.
5. Confirme os direitos de uso das imagens e use fotos dos produtos reais que você tem autorização para anunciar.
6. Confira preço, estoque, procedência, garantia, condições de pagamento, entrega e política de troca.
7. Publique em uma hospedagem estática (por exemplo, GitHub Pages, Netlify ou Azure Static Web Apps).

## Observações
- Os preços são apenas exemplos, não cotações reais.
- As imagens são carregadas de URLs externas e dependem de conexão com a internet; substitua por fotos autorizadas dos aparelhos reais.
- O site não processa pagamento nem controla estoque. O pedido é iniciado no WhatsApp.
- Este projeto não é afiliado nem representa oficialmente a Apple. Não use logotipos ou alegações de revendedor autorizado sem ter autorização.
